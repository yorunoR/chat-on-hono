# アーキテクチャ

## 技術スタック

| 用途 | ライブラリ / ツール |
| --- | --- |
| ランタイム | Node.js 24 (`containers/api/local/Dockerfile`) |
| Web フレームワーク | [Hono](https://hono.dev/) + `@hono/node-server` |
| ORM | [Drizzle ORM](https://orm.drizzle.team/) (`node-postgres` ドライバ) |
| マイグレーション | drizzle-kit |
| DB | PostgreSQL 18 (`compose.yaml` の `db` サービス) |
| 管理画面 | `@sson0-er/drizzle-admin` (Django Admin 風のサーバーレンダリング CRUD) |
| 言語 | TypeScript (ESM, `module: NodeNext`) |
| Lint / Format | Biome |
| パッケージマネージャ | pnpm |
| 開発時実行 | tsx (`tsx watch`) |

## ディレクトリ構成

```
api/
├── docs/                       # このドキュメント (NN_日本語名.md、番号順に読む)
├── drizzle/                    # drizzle-kit が生成するマイグレーション SQL (Biome 対象外)
│   ├── down/                   # ロールバック用 SQL (手書き。`pnpm db:rollback` で使用)
│   └── meta/                   # マイグレーションのスナップショット / ジャーナル
├── src/
│   ├── index.ts                # エントリポイント。Hono アプリの定義とサーバー起動
│   ├── admin/
│   │   ├── index.ts            # 管理画面 (drizzle-admin) の設定とモデル登録
│   │   └── password.ts         # パスワードのハッシュ化 / 検証 (scrypt)
│   ├── db/
│   │   ├── index.ts            # Drizzle の DB クライアント (`db`)
│   │   └── schema/
│   │       ├── index.ts        # 全テーブルの re-export (drizzle-kit はここを参照)
│   │       ├── admin-users.ts  # admin_users テーブル
│   │       ├── users.ts        # users テーブル
│   │       ├── chat_sessions.ts  # chat_sessions テーブル
│   │       └── columns/
│   │           └── timestamps.ts  # 共通カラム (created_at / updated_at)
│   └── scripts/
│       ├── create-admin-user.ts   # 管理者ユーザー作成 CLI
│       ├── db-rollback.ts         # 最後のマイグレーションを戻す (`pnpm db:rollback`)
│       └── db-status.ts           # マイグレーション適用状況の表示 (`pnpm db:status`)
├── biome.json
├── drizzle.config.ts           # drizzle-kit 設定
├── package.json
├── pnpm-workspace.yaml
└── tsconfig.json
```

### 規約

- ESM のため、相対 import には `.js` 拡張子を付ける (例: `./db/index.js`)。
- テーブルは `src/db/schema/<table-name>.ts` に定義し、`src/db/schema/index.ts` から export する。
- 共通カラムは `src/db/schema/columns/` に置き、スプレッドで利用する (`...timestamps`)。

## エンドポイント

サーバーは `3000` 番ポートで起動します (`src/index.ts`)。

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/` | 動作確認用。`Hello Hono!` を返す |
| GET | `/health/db` | DB 疎通確認 (`select 1`)。成功時 `{"status":"ok"}` |
| * | `/admin/*` | 管理画面。詳細は [04_管理画面.md](./04_管理画面.md) |

### ミドルウェア

| 対象 | ミドルウェア | 目的 |
| --- | --- | --- |
| `/admin/*` | `bodyLimit` (1 MiB) | drizzle-admin がリクエストボディサイズを制限しないため |
