# アーキテクチャ

## 技術スタック

| 用途 | ライブラリ / ツール |
| --- | --- |
| ランタイム | Node.js (`containers/api/local/Dockerfile`) |
| Web フレームワーク | [Hono](https://hono.dev/) + `@hono/node-server` |
| ORM | [Drizzle ORM](https://orm.drizzle.team/) (`node-postgres` ドライバ) |
| マイグレーション | drizzle-kit |
| DB | PostgreSQL (`compose.yaml` の `db` サービス) |
| 管理画面 | `@sson0-er/drizzle-admin` (Django Admin 風のサーバーレンダリング CRUD) |
| 言語 | TypeScript (ESM, `module: NodeNext`) |
| Lint / Format | Biome |
| パッケージマネージャ | pnpm (サプライチェーン攻撃対策の設定は [02_開発環境.md](./02_開発環境.md) を参照) |
| 開発時実行 | tsx (`tsx watch`) |

## ディレクトリ構成

```
api/
├── docs/          # このドキュメント
├── drizzle/       # drizzle-kit が生成するマイグレーション (Biome 対象外)
│   └── down/      # ロールバック用 SQL (手書き)
└── src/
    ├── index.ts   # エントリポイント。ルーティングとサーバー起動
    ├── admin/     # 管理画面
    ├── db/        # DB クライアントとスキーマ
    └── scripts/   # CLI スクリプト (package.json の scripts から実行)
```

### 規約

- ESM のため、相対 import には `.js` 拡張子を付ける (例: `./db/index.js`)。
- テーブルは `src/db/schema/<table-name>.ts` に定義し、`src/db/schema/index.ts` から export する。
- 共通カラムは `src/db/schema/columns/` に置き、スプレッドで利用する (`...timestamps`)。
