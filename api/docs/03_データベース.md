# データベース

## 接続

- 接続先は環境変数 `DATABASE_URL` で指定します。未設定の場合は起動時にエラーになります (`src/db/index.ts`, `drizzle.config.ts`)。
- ローカルでは `compose.yaml` の `db` サービス (PostgreSQL 18) を使用します。
- 初回起動時に `db/init/init-user-psql.sh` が実行され、以下が作成されます。

| 種類 | 名前 | 備考 |
| --- | --- | --- |
| ユーザー | `developer` / `password` | `CREATEDB`, `CREATEROLE` 権限 |
| DB | `api_dev` | 開発用 |
| DB | `api_test` | テスト用 |

## スキーマ

スキーマは `src/db/schema/` に TypeScript で定義します。

### admin_users

管理画面にログインする管理者ユーザー (`src/db/schema/admin-users.ts`)。

| カラム | 型 | 制約 / デフォルト | 説明 |
| --- | --- | --- | --- |
| `id` | integer | PK, `GENERATED ALWAYS AS IDENTITY` | |
| `email` | varchar(255) | NOT NULL, UNIQUE (`ix_admin_users_email`) | ログイン ID |
| `hashed_password` | varchar(255) | NOT NULL | `<salt>:<hash>` (hex) 形式の scrypt ハッシュ |
| `is_active` | boolean | NOT NULL, default `true` | `false` の場合ログイン不可 |
| `is_superuser` | boolean | NOT NULL, default `false` | 現時点では未使用 |
| `created_at` | timestamptz | NOT NULL, default `now()` | |
| `updated_at` | timestamptz | NOT NULL, default `now()` | Drizzle 経由の更新時に自動更新 (`$onUpdate`) |

### 共通カラム

`src/db/schema/columns/timestamps.ts` の `timestamps` をスプレッドすると `created_at` / `updated_at` が追加されます。
`updated_at` の自動更新は Drizzle の `$onUpdate` によるもので、DB トリガーではありません (生 SQL での更新時は反映されません)。

## マイグレーション

マイグレーションファイルは drizzle-kit で `drizzle/` に生成します。

| ファイル | 内容 |
| --- | --- |
| `0000_create_admin_users.sql` | `admin_users` テーブル作成 |

### テーブル追加・変更の手順

1. `src/db/schema/` にテーブルを定義 / 変更する
2. 新規テーブルの場合は `src/db/schema/index.ts` から export する
3. マイグレーションを生成する: `pnpm db:generate --name <name>`
4. 生成された SQL を確認し、適用する: `pnpm db:migrate`
5. このドキュメントのスキーマ・マイグレーション一覧を更新する

その他のコマンドは [02_開発環境.md](./02_開発環境.md) を参照してください。
