# api ドキュメント

`api/` 配下の API サーバーに関するドキュメントです。機能追加・構成変更の際は該当ドキュメントも合わせて更新してください。
コードを見ればわかる内容 (カラム定義、設定値、コマンド一覧など) は書き写さず、理由・意図、手順、複数ファイルにまたがる規約など、コードから読み取りにくいことを書きます。
ファイル名先頭の番号順に読むことを想定しています。新しいドキュメントは `NN_日本語名.md` の形式で追加し、この目次にも追記してください。

| ドキュメント | 内容 |
| --- | --- |
| [01_構成.md](./01_構成.md) | 技術スタック、ディレクトリ構成、規約、今後の方針 |
| [02_開発環境.md](./02_開発環境.md) | 開発環境、環境変数、パッケージ管理、コマンド |
| [03_データベース.md](./03_データベース.md) | DB 接続、スキーマの規約、マイグレーション |
| [04_管理画面.md](./04_管理画面.md) | 管理画面 (`/admin`) と管理者ユーザー |
