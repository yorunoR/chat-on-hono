# 管理画面

`@sson0-er/drizzle-admin` による Django Admin 風の管理画面を `/admin` で提供します (`src/admin/index.ts`)。

- URL: http://localhost:3000/admin
- ログイン画面の Username にはメールアドレスを入力します。

## 設定

| 項目 | 値 / 説明 |
| --- | --- |
| `basePath` | `/admin` |
| `secret` | 環境変数 `ADMIN_SECRET` (Cookie 署名用、32 文字以上)。未設定ならライブラリが起動時にエラーにする |
| 認証 | `admin_users` を `email` で検索し、`is_active = true` かつパスワード一致でログイン可 |
| ボディサイズ制限 | `src/index.ts` で 1 MiB に制限 |

## 登録モデル

### admin_users

| オプション | 設定 |
| --- | --- |
| 一覧表示 | `id`, `email`, `isActive`, `createdAt` |
| 検索 | `email` |
| 読み取り専用 | `createdAt`, `updatedAt` |
| パスワード欄 | `password` ウィジェット。常に空で表示され、空のまま保存すると現在のパスワードを維持 |
| バリデーション | パスワードは 8 文字以上 (`PASSWORD_MIN_LENGTH`) |
| 保存前フック | 入力された平文パスワードを scrypt でハッシュ化して保存 |

新しいテーブルを管理画面に出す場合は `admin.register(table, options)` を `src/admin/index.ts` に追加し、この一覧にも追記してください。

## パスワード

`src/admin/password.ts` で Node.js 標準の `crypto.scrypt` を使用します。

- 保存形式: `<salt(16 byte, hex)>:<hash(64 byte, hex)>`
- 検証は `timingSafeEqual` で比較

## 管理者ユーザーの作成

最初の管理者は CLI で作成します。パスワードは対話的に入力します (TTY 必須)。

```sh
docker compose exec api pnpm admin:create admin@example.com
```

同じメールアドレスのユーザーが既に存在する場合は、パスワードを更新して有効化 (`is_active = true`) します。
