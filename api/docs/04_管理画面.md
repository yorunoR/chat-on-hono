# 管理画面

`@sson0-er/drizzle-admin` による Django Admin 風の管理画面を `/admin` で提供します (`src/admin/index.ts`)。

- ログイン画面の Username にはメールアドレスを入力します。
- 新しいテーブルを管理画面に出す場合は `admin.register(table, options)` を `src/admin/index.ts` に追加します。
- drizzle-admin はリクエストボディのサイズを制限しないため、`src/entrypoints/app.ts` で `/admin/*` に `bodyLimit` をかけています。

## 管理者ユーザーの作成

最初の管理者は CLI で作成します。パスワードは対話的に入力します (TTY 必須)。

```sh
docker compose exec api pnpm admin:create admin@example.com
```

同じメールアドレスのユーザーが既に存在する場合は、パスワードを更新して有効化します。
