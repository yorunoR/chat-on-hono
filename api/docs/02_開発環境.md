# 開発環境

## コンテナ

Docker Compose (`compose.yaml`) で `api` (API サーバー)、`db` (PostgreSQL)、`ai` (AI エージェント作業用) の 3 つのコンテナを起動します。

- `api` は `./api` を `/api` にマウントしており、`tsx watch` によりソース変更で自動再起動します。
- コンテナはホストの UID/GID で動作します (`Makefile` が `HOST_UID` / `HOST_GID` を設定)。`docker compose` を直接使う場合はこれらを export してください。

## 環境変数

`.env.api.local.sample` をリポジトリルートに `.env.api.local` としてコピーして設定します。各変数の説明はサンプルファイルのコメントを参照してください。

API サーバーが読む環境変数は `src/env.ts` にまとめ、`process.env` を直接読まずに `env` 経由で参照します。ただし `drizzle.config.ts` は drizzle-kit が `src/` と別に読み込むため、`DATABASE_URL` を直接読んでいます。

`ai` コンテナは `.env.ai.local.sample` をコピーした `.env.ai.local` を読み込みます。AI エージェントは専用の `api_ai` DB にのみ接続し、`api_dev` / `api_test` には接続させません (詳細は [03_データベース.md](./03_データベース.md))。

## パッケージ管理 (サプライチェーン攻撃対策)

- `.npmrc` でレジストリを `https://npm.flatt.tech/` (Flatt Security) にしている。
- `pnpm-workspace.yaml` の `minimumReleaseAge: 10080` で、公開から 7 日未満のバージョンはインストールしない。

## コマンド

コマンドは `package.json` の `scripts` を参照し、`api` コンテナ内 (`docker compose exec api <command>`) で実行します。

- `pnpm db:drop` (`drizzle-kit drop`) は使わない。理由は [03_データベース.md](./03_データベース.md#マイグレーションの作り直し) を参照。
