# 開発ガイド

## 開発環境

Docker Compose で以下のサービスを起動します (`compose.yaml`)。

| サービス | 説明 | ポート |
| --- | --- | --- |
| `api` | API サーバー。起動時に `pnpm install` → `pnpm dev` を実行 | 3000 |
| `db` | PostgreSQL 18 | 5432 |
| `ai` | AI エージェント (Claude Code / Codex) 作業用コンテナ | - |

- `api` は `./api` を `/api` にマウントしており、`tsx watch` によりソース変更で自動再起動します。
- `api` は `db` のヘルスチェック成功後に起動します。
- コンテナはホストの UID/GID で動作します (`Makefile` が `HOST_UID` / `HOST_GID` を設定)。`docker compose` を直接使う場合はこれらを export してください。

## 環境変数

`.env.api.local.sample` をリポジトリルートに `.env.api.local` としてコピーして設定します。

| 変数 | 必須 | 説明 |
| --- | --- | --- |
| `DATABASE_URL` | ○ | PostgreSQL 接続文字列。ローカルは `postgres://developer:password@db:5432/api_dev` |
| `ADMIN_SECRET` | ○ | 管理画面の Cookie 署名用 (32 文字以上)。例: `openssl rand -base64 48` |

## コマンド

`api` コンテナ内 (`docker compose exec api <command>`) で実行します。

| コマンド | 説明 |
| --- | --- |
| `pnpm dev` | 開発サーバー起動 (`tsx watch`) |
| `pnpm build` | `dist/` にビルド |
| `pnpm start` | ビルド済みサーバーを起動 |
| `pnpm lint` | Biome によるチェック |
| `pnpm lint:fix` | Biome による自動修正 |
| `pnpm type` | 型チェック (`tsc --noEmit`) |
| `pnpm db:generate` | スキーマからマイグレーション SQL を生成 |
| `pnpm db:migrate` | マイグレーションを適用 |
| `pnpm db:push` | マイグレーションを生成せずにスキーマを DB に反映 (試行用) |
| `pnpm db:studio` | Drizzle Studio を起動 |
| `pnpm admin:create <email>` | 管理者ユーザーを作成 / パスワード更新 |

## Make ターゲット (リポジトリルート)

| ターゲット | 説明 |
| --- | --- |
| `make up` | `docker compose up` |
| `make build` | `docker compose build` |
| `make stop` / `make down` | 停止 / 削除 |
| `make b` | `ai` コンテナで bash |
| `make cl` / `make cx` | `ai` コンテナで Claude Code / Codex を起動 |
